Diffusion Meets Flow Matching: Two Sides of the Same Coin

An exploration of the equivalence between diffusion models and Gaussian flow matching frameworks in generative modeling.

Yichen Sheng
December 29, 2024

Contents

Overview

Flow matching and diffusion models are two popular frameworks in generative modeling. Despite seeming similar, there is some confusion in the community about their exact connection. In this post, we aim to clear up this confusion and show that diffusion models and Gaussian flow matching are the same.

This is great news—it means you can use the two frameworks interchangeably and mix techniques developed from both.

Diffusion Models

A diffusion process gradually destroys an observed datapoint $\mathbf{x}$ (such as an image) over time $t$, by mixing the data with Gaussian noise. The noisy data at time $t$ is given by a forward process:

\[\mathbf{z}_t = \alpha_t \mathbf{x} + \sigma_t \boldsymbol{\epsilon}, \quad \text{where} \quad \boldsymbol{\epsilon} \sim \mathcal{N}(0, \mathbf{I})\]

Here $\alpha_t$ and $\sigma_t$ define the noise schedule. A noise schedule is called variance-preserving if $\alpha_t^2 + \sigma_t^2 = 1$.

The Reverse Process

To generate new samples, we can “reverse” the forward process:

  1. Initialize the sample $\mathbf{z}_1$ from a standard Gaussian
  2. Given the sample $\mathbf{z}_t$ at time step $t$, predict what the clean sample might look like with a neural network (denoiser model) $\hat{\mathbf{x}} = \hat{\mathbf{x}}(\mathbf{z}_t; t)$
  3. Project it back to a lower noise level $s$ with the same forward transformation

The DDIM update is given by:

\[\mathbf{z}_{s} = \alpha_{s} \hat{\mathbf{x}} + \sigma_{s} \hat{\boldsymbol{\epsilon}}\]

where $\hat{\boldsymbol{\epsilon}} = (\mathbf{z}_t - \alpha_t \hat{\mathbf{x}}) / \sigma_t$.

Flow Matching

In flow matching, we view the forward process as a linear interpolation between the data $\mathbf{x}$ and a noise term $\boldsymbol{\epsilon}$:

\[\mathbf{z}_t = (1-t) \mathbf{x} + t \boldsymbol{\epsilon}\]

This corresponds to the diffusion forward process if the noise is Gaussian and we use the schedule $\alpha_t = 1-t, \sigma_t = t$.

Using simple algebra, we can derive that $\mathbf{z}t = \mathbf{z}{s} + \mathbf{u} \cdot (t - s)$ for $s < t$, where $\mathbf{u} = \boldsymbol{\epsilon} - \mathbf{x}$ is the “velocity” or “vector field”.

The Equivalence

Both frameworks share the same essence:

Aspect Diffusion Flow Matching
Forward process Same (with appropriate schedule) Same
Sampling Iterative denoising Iterative flow following
Network output $\hat{\mathbf{x}}$ or $\hat{\boldsymbol{\epsilon}}$ $\hat{\mathbf{u}}$ (velocity)

Key Insight: The DDIM update can be expressed as a flow matching update with appropriate reparametrization. This means techniques from one framework can be applied to the other!

Code Example

Here’s a simple example showing the equivalence in PyTorch:

import torch

def diffusion_forward(x, t, alpha_t, sigma_t):
    """Diffusion forward process"""
    eps = torch.randn_like(x)
    z_t = alpha_t * x + sigma_t * eps
    return z_t, eps

def flow_matching_forward(x, t):
    """Flow matching forward (linear interpolation)"""
    eps = torch.randn_like(x)
    alpha_t = 1 - t
    sigma_t = t
    z_t = alpha_t * x + sigma_t * eps
    return z_t, eps

# Both are equivalent with alpha_t = 1-t, sigma_t = t

Practical Implications

What Flow Matching Brings

  1. Network output: Flow matching proposes a vector field parametrization that may affect training dynamics
  2. Simple noise schedule: Uses $\alpha_t = 1-t$ and $\sigma_t = t$, with the same update rule as DDIM

Mix and Match

After training a flow matching model, you can use:

  • Deterministic sampling (standard flow ODE)
  • Stochastic sampling (add noise during sampling, like DDPM)

This flexibility comes from the equivalence between the two frameworks.

Conclusion

The equivalence between diffusion models and Gaussian flow matching allows practitioners to:

  • Use techniques from both frameworks interchangeably
  • Choose the most intuitive formulation for their specific application
  • Combine stochastic and deterministic sampling methods
